# 상품 중심 커머스 백엔드 (프로젝트명 미정)

> CJ ENM 커머스부문(온스타일) 백엔드개발 직무 지원을 위해 진행한 사이드 프로젝트입니다.

## 왜 만들었나

- SI·공공기관 프로젝트 위주의 경력이라 "직접 설계하고 운영까지 고려한 서비스" 경험이 부족했습니다.
- 이 공백을 채우기 위해, 지원 직무의 실제 업무(상품/카테고리/기획전 API, 검색·추천, AWS 운영)를 참고해 기능 범위를 정하고 직접 설계·개발했습니다.
