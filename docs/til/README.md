# TIL (Today I Learned)

매일 진행하면서 새로 알게 된 개념을 `YYYY-MM-DD.md`로 정리합니다.
면접에서 "이건 왜 이렇게 했나요?"에 답할 수 있도록, 개념 설명뿐 아니라 **이 프로젝트에서 어떻게 쓰였는지**를 함께 적습니다.

## 작성 형식

```markdown
# YYYY-MM-DD

## 오늘 한 일
- 커밋/작업 요약

## 배운 개념
### 개념 이름
- **한 줄 정의**:
- **왜 필요한가**:
- **이 프로젝트에서**: (파일/코드 위치)
- **대안/트레이드오프**:

## 헷갈렸던 점 / 더 볼 것
- 
```
