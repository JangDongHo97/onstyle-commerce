## 배운 개념

### `spring-boot-starter-webmvc`
- **한 줄 정의**: Spring MVC(`@RestController` 등), 내장 Tomcat, Jackson(JSON 변환)을 한 번에 넣어주는 웹 스타터.
- **왜 필요한가**: JPA만 있으면 DB 저장은 되지만 HTTP로 호출할 방법이 없다. Controller를 만들고 JSON을 주고받으려면 웹 계층이 필요하다.
- **이 프로젝트에서**: `build.gradle`에 추가. 앞으로 `CategoryController`, `ProductController`가 이 위에서 동작하고, Swagger UI도 웹 계층이 있어야 뜬다.
- **대안/트레이드오프**: Boot 3까지는 `spring-boot-starter-web`이었는데 Boot 4에서 `webmvc`로 이름이 바뀌었다(MVC와 WebFlux 구분). 옛 이름도 deprecated 호환으로 남아 있지만 새 프로젝트는 새 이름을 쓴다. 비동기·논블로킹이 핵심이면 `webflux`가 대안이지만, JPA(블로킹) 기반이라 MVC가 맞다.

### springdoc 버전과 Spring Boot 메이저 버전
- **한 줄 정의**: springdoc-openapi는 Spring Boot 메이저 버전과 메이저 버전을 맞춰 릴리스한다(Boot 3 → 2.x, Boot 4 → 3.x).
- **왜 필요한가**: 메이저가 어긋나면 내부 API 변경 때문에 기동 실패나 문서 누락이 생길 수 있다.
- **이 프로젝트에서**: Boot 4.1.1이라 2.6.0에서 3.1.1로 올렸다. 검색 결과상 3.1.1은 Boot 4.0.3 기준이었지만, 4.1.1에서도 기동과 Swagger UI 200으로 실제 확인했다.
- **대안/트레이드오프**: 문서 요약만 믿지 않고 실제로 띄워서 검증하는 게 안전하다.

### `open-in-view` (OSIV)
- **한 줄 정의**: 켜져 있으면(Boot 기본값) 영속성 컨텍스트가 요청 시작부터 응답이 끝날 때까지 유지되어, Controller와 뷰 렌더링 단계에서도 LAZY 로딩이 된다.
- **왜 필요한가**: 편의 기능이다. 대신 DB 커넥션을 요청 내내 붙잡고 있어서 트래픽이 많으면 커넥션 풀이 고갈될 수 있다.
- **이 프로젝트에서**: 웹 계층을 추가하자 `spring.jpa.open-in-view is enabled by default` 경고가 떴다. 아직 설정은 바꾸지 않았다.
- **대안/트레이드오프**: `false`로 끄면 커넥션을 빨리 반환하지만, Service 밖에서 LAZY 필드에 접근하면 `LazyInitializationException`이 난다. 그래서 Service에서 필요한 데이터를 DTO로 변환해 반환해야 한다. 이 프로젝트의 `Category.parent`/`children`, `Product.category`가 LAZY라 이 결정이 곧 중요해진다.
